## Présentation

Ce projet a été réalisé dans le cadre de l'exercice ADAPage. Il fallait créer une page index et cartes en HTML.
Il fallait aussi créer deux fichier CSS un pour chaque page. Comprendre et s'entrainer dans l'utilisation des
deux languages.

## Fonctionnalités

**Responsive Design :** Interface entièrement adaptée aux mobiles, tablettes et ordinateurs (approche Mobile-First).
**Animations CSS :** Micro-interactions fluides sur les boutons et les liens de navigation.
**Architecture CSS :** Organisation rigoureuse des styles (ex: utilisation de variables CSS pour le thème de couleurs).

## Technologies Utilisées

- **HTML5** - Structuration sémantique du contenu.
- **CSS3** - Flexbox, CSS Grid, Variables CSS (Custom Properties), et Media Queries.
